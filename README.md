# Skills für Leuffen Webdienste

## Install

```bash
git submodule add -b main git@github.com:l2fn/leu-ai-skills.git .pi/skills/leu-ai-skills

## Laden / aktualisieren
git submodule update --init --recursive
```

Bei Änderungen am Submodule: Erst submodules commit / push - dann im Hauptprojekt commit / push.
